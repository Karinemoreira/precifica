# Precifica

App Vue 3 (Vite + TypeScript) para precificar itens a partir de **custo** e **margem (%)** → **preço de venda sugerido**. MVP front-only, sem backend.

- Roadmap detalhado: [BACKLOG.md](./BACKLOG.md)

## Requisitos

- Node.js 20+ (recomendado LTS)

## Comandos

```bash
npm install
npm run dev      # desenvolvimento
npm run build    # produção
npm run preview  # pré-visualizar build
npm run test     # testes (Vitest)
npm run lint     # ESLint
```

## Stack

Vue 3, Vite, TypeScript, Vitest, ESLint (`eslint-plugin-vue` + `typescript-eslint`).
